# 发票PDF自动重命名工具

这是一个用于自动提取发票号码并批量重命名PDF文件的网页工具，无需安装软件，直接在浏览器使用。

## ✨ 功能特点
- 自动识别PDF发票中的发票号码
- 批量处理多个文件
- 直接下载重命名后的文件
- 无需上传文件到服务器，数据安全不泄露

## 🚀 使用方法
1.  打开网页
2.  点击「选择PDF文件」，上传需要处理的发票PDF
3.  点击「开始处理」，工具会自动提取发票号码
4.  处理完成后，文件会自动以「发票号码.pdf」格式下载到本地

## 📌 适用场景
- 财务人员批量整理电子发票
- 个人报销发票归档
- 快速给发票文件命名，方便查找和管理
